# 共有写像と直交整列の共同学習による未見モデル適応のPoC計画

計画案｜2026年10月18日

本計画は、[shared_mapping_research_plan.md](./shared_mapping_research_plan.md) とその実験結果を受け、共有非線形写像 φ の学習手順を再検討する追試である。既存の本試験結果を書き換えず、既存の固定整列条件を再現可能な比較対象として、共同学習条件を新たに評価する。ここに記す数値は実装前の推奨仕様であり、開発試行後、本試験の実行前に確定・記録する。

## 要旨

従来の共有写像学習では、通常活動だけから推定した各モデルの直交整列 A_m を固定し、介入損失で共有写像 φ を学習した。この計画では、同じ初期整列と同じ介入データを用いて、(1) A_mを固定してφだけを学習する従来条件と、(2) φと訓練側A_mを共同更新する条件を比較する。NN本体は固定し、A_mは直交性を保つ。学習済み・ランダムMLPのleave-one-model-out評価を行い、未見モデルでは両条件とも通常活動由来の同じ初期整列から始め、φを固定してA_testだけを介入データで適応する。適応前と、同じ適応予算後の未使用テスト介入でIIAを測る。

主な推論対象は、通常活動整列を固定したままφを学習する手順が、φの未見モデル適応を妨げていたかどうかである。共同学習が転移を保証するわけではなく、A_mの更新を許すことによる自由度増加も同時に生じるため、得られる差は「整列を介入損失で更新可能にした学習手順」の効果として解釈する。

## 1. 研究質問と仮説

### 1.1 主研究質問

> 通常活動による整列を固定して学習したφと、整列を直交制約下でφと共同学習したφでは、同じ未見側適応条件のもとで、未見モデルのIIAと適応効率に差が生じるか。

### 1.2 仮説

- **H1（共同学習による改善）**：共同学習条件は、未見側の同一の介入適応予算において、固定整列条件より高いテストIIAを示す、または少ない適応例で同等のIIAに達する。
- **H0相当（差がない）**：差が小さい場合、通常活動整列を固定したことだけでは転移失敗を説明できない。直交制約、φの容量・最適化、モデル間の表現差などが残る。
- **両条件が適応で回復**：従来φに再利用可能な情報はあったが、通常活動整列だけではそれを利用できなかった可能性が高まる。ただし、共有写像の学習手順の優位性を示すには共同学習条件との直接比較が必要である。

改善・不改善のどちらも結果として報告し、学習側のIIAだけを根拠に転移成功とは判定しない。

## 2. 比較条件

各条件で、同じMLP群、leave-one-model-out分割、介入データ、φの初期重み、乱数seed、最大更新数を対応づける。

| 条件 | 訓練側A_m | 訓練対象 | 役割 |
| --- | --- | --- | --- |
| **固定整列（基準）** | 通常活動から推定した直交整列A_m⁰に固定 | 共有φのみ | 従来の共有写像学習を再現 |
| **共同学習（主比較）** | A_m⁰から初期化し、直交性を保って更新 | 共有φと訓練側A_m | 整列の介入損失による更新を許す |

両条件ともNN重みは固定する。座標分割（左右の高水準変数に割り当てる座標）、損失、訓練側モデル、介入例を同じにする。個別モデルごとのφを追加条件にする場合は診断対照とし、主比較に混ぜない。

### 2.1 目的関数

モデルmの介入損失を \(\mathcal L_{\mathrm{iv}}^{(m)}(\phi,A_m)\) とすると、固定整列条件は

\[
\min_\phi \frac{1}{|\mathcal M_{\mathrm{train}}|}
\sum_{m\in\mathcal M_{\mathrm{train}}}
\mathcal L_{\mathrm{iv}}^{(m)}(\phi,A_m^0)
\]

を最小化する。共同学習条件は

\[
\min_{\phi,\{A_m\}}
\frac{1}{|\mathcal M_{\mathrm{train}}|}
\sum_{m\in\mathcal M_{\mathrm{train}}}
\mathcal L_{\mathrm{iv}}^{(m)}(\phi,A_m),
\qquad A_m^\top A_m=I,\quad A_{\mathrm{ref}}=A_{\mathrm{ref}}^0
\]

を最小化する。損失は既存実装と同じ反実仮想ラベルに対する交差エントロピーとする。

共同学習では、参照モデルの整列を初期値 \(A_{\mathrm{ref}}^0\) に固定し、他モデルの整列のみを更新する。これはφと全A_mに共通する座標回転を同時に動かす退化自由度を抑え、共有座標系の基準を保つためである。参照モデルの選択は従来計画どおり訓練側モデルのseed順で事前固定し、IIAによる選択はしない。

### 2.2 直交性の実装要件

A_mを通常の自由行列として学習してはならない。初期整列から直交行列を保つパラメータ化（例：\(A_m=A_m^0\exp(K_m)\)、\(K_m^\top=-K_m\)）または同等の直交制約付き最適化を用いる。各保存checkpointで \(\|A_m^\top A_m-I\|_{\max}\) を検査し、許容誤差を超える実行は無効として扱う。実装方式と数値許容誤差はPoC後に固定する。

## 3. 未見モデル適応と情報分割

各foldで訓練に使わないモデルを未見モデルとする。φは訓練後に固定し、未見モデルではA_testだけを更新する。φや訓練済みNN、座標分割を未見データで更新しない。

### 3.1 初期整列

未見モデルの \(A_{\mathrm{test}}^0\) は、従来実装と同じ通常活動ベースの直交Procrustes整列で推定する。校正通常入力と、参照モデルの活動は両条件で同一とする。共同学習で更新された訓練側整列を使って未見モデル整列を再推定しない。これにより、両条件に共通の「適応前」評価点を設ける。

### 3.2 介入適応データ

既存の介入train/dev/test分割を維持し、用途を次のように固定する。

- **adapt/train**：A_testの勾配更新に使う。既存trainから選んだ部分集合を用いる。
- **adapt/dev**：停止・checkpoint選択だけに使う。既存dev介入を用い、テスト結果を見て選択しない。
- **final test**：最後のIIA評価だけに使う。適応、停止、ハイパーパラメータ選択には一切使わない。

適応例数はPoCで **0、256、1,024、4,096、10,000** を比較する。0例は適応前の \(A_{\mathrm{test}}^0\) に相当する。各例数の集合は同じseedの入れ子subsetとし、モデル条件間・φ条件間で同一の介入IDを使う。適応データは高水準変数の介入種別（左・右・両方）を可能な限り均衡させる。適応例の乱数seedとIDを保存する。

各条件・例数に対し、同じ最大optimizer更新数（推奨2,000更新）、batch size（推奨256）、optimizer、停止規則を使う。adapt/devによる早期停止を行う場合、patienceとcheckpoint選択基準を開発段階で固定し、実際の更新数も記録する。データ量曲線と計算予算を混同しないよう、各例数について例の再標本化を含む総更新数を揃える。

## 4. 課題・モデル・学習仕様

既存計画と直接比較可能にするため、以下は変更しない。

| 項目 | PoC仕様 |
| --- | --- |
| 課題 | Both Equality Relations（階層的等値判定） |
| 対象層 | 第1隠れ層、16次元 |
| 高水準変数 | 左右各8座標、共通の固定分割 |
| MLP | 既存計画どおり。学習済み状態と同一初期化由来のランダム状態 |
| モデル群 | 開発seed 5234、4641。本試験候補は4287、3837、9097、2635、5137 |
| 整列初期値 | 通常活動ベースの直交Procrustes |
| 共有写像 | RevNet 10ブロック、内部幅128 |
| φの学習 | 固定整列・共同学習とも同一の介入損失と予算 |
| データ | 既存の固定介入データ・校正通常入力を再利用 |

既存の本試験5seedは最終確認に用いる。開発seedは実装確認と仕様確定専用とし、本試験集計に含めない。まず開発seedで直交性、勾配伝播、介入実装、適応ループを検証し、仕様凍結後に本試験へ進む。

### 4.1 φ学習の対応付け

各fold・状態・φ初期化ごとに、固定整列条件と共同学習条件をpaired runとして実行する。両方とも同一のφ初期stateから開始する。既存条件は初期化2回なので、最低2組の対応runを実施し、最良runだけを選ばず両初期化を報告する。

既存共有学習の介入batch（1更新あたり訓練側モデルごとに同じ介入ID、損失はモデル平均）、学習率、epoch上限、開発損失に基づくcheckpoint選択を原則継承する。具体的には既存full設定の φ学習率0.001、最大50 epoch、patience 5、開発損失改善閾値0.001、ReduceLROnPlateau factor 0.5 / patience 10を出発点とする。固定条件と共同条件の間で、最大データ露出数と更新数を一致させる。A用学習率はφと分けて設定し、PoCで有限な学習・安定した直交性を確認後、本試験前に固定する。テストIIAを見て学習率を調整しない。

## 5. 評価指標と解析

### 5.1 主評価

主指標は未見モデルの最終test介入に対するIIA（介入後予測と反実仮想ラベルの一致率）である。各foldで、次を条件別・例数別に記録する。

1. 適応前IIA（\(A_{\mathrm{test}}^0\)、例数0）
2. A_test適応後のtest IIA
3. 適応前からの改善量
4. 同一モデルの個別φで得たIIAとの差（個別 − 共有）
5. adapt/train・adapt/dev・testの損失とIIA、A_testの直交誤差
6. 適応に要した実更新数と経過時間

主要な対比は、同一fold・モデル状態・φ初期化・適応subsetにおける「共同学習 − 固定整列」のtest IIA差と、例数別の適応曲線である。適応前IIAも併記し、ゼロショット転移と介入適応後の転移を分ける。

### 5.2 集計と不確実性

モデル数は5でfold間も独立ではないため、foldを独立標本とみなした有意差検定を主張の根拠にしない。各モデルの値、平均、範囲、paired差を全て示す。介入test例の有限標本不確実性は、モデル間差と分離して必要に応じて例単位bootstrap区間を示す。学習seed間のばらつきも別に報告する。

通常課題の精度は各MLPについて併記する。ランダムモデルは課題能力を伴わない高IIA候補の対照だが、既存結果では高い個別IIAが得られたseedは一部に限られる。よって「ランダム群一般の高IIAを排除した」とは結論せず、各モデルの通常精度と個別IIAを明示する。

## 6. 事前固定する判定と解釈

| 観察 | 解釈 |
| --- | --- |
| 共同学習が複数の適応例数でpairedに高いtest IIAを示す | 通常活動整列の固定が障害の一因だった証拠。ただしA更新自由度の増加を含む効果 |
| 共同学習が同等IIAに少ない適応例で到達する | 未見側での整列適応効率を高めた可能性 |
| 適応前は差があり、A_test適応後に両条件が回復 | 共有写像に再利用可能な情報がある一方、通常活動整列だけでは十分でない可能性 |
| 両条件とも低いまま | 共同学習だけでは転移障害を解消しない。直交制約、共有写像の容量・最適化、機構差等が残る |
| 共同学習の訓練IIAだけが上がり、未見testに差がない | 訓練モデル集合への適合が強まった結果と解釈し、転移改善とは呼ばない |
| ランダム群でも同等の改善 | 共同学習や未見適応だけでは課題能力を伴う対応を選別できない可能性 |

改善閾値は結果確認前に、IIAの絶対差と適応例数の双方について定める。PoC段階では効果量と実現可能性を推定し、確認試験に使う閾値・必要な反復数を凍結する。小標本である現行5seedだけで確証的な一般化を主張しない。

PoCの実務上の暫定基準は、事前指定した適応例数の少なくとも1点で、共同学習条件が固定整列条件に対して平均paired test IIAを **0.05以上**改善し、かつモデル別paired差の過半数が正であることとする。適応効率の改善は、固定整列条件と同程度のtest IIAに、共同学習条件が少なくとも4分の1の適応例数で達した場合と定義する。同程度のIIAの許容差、比較する適応点、seed集計方法は開発結果を見る前に確定する。この基準はPoCの継続判断用であり、5モデルで統計的確証を得たことを意味しない。

## 7. 対照・失敗診断

- **既存条件の再現**：共同学習を加える前に、固定整列条件の再実行が既存結果の範囲に入ることを確認する。
- **同一初期化の対照**：paired runでφ初期state、データ順、介入IDを一致させ、条件差を保存する。
- **参照固定の対照**：参照Aを固定する実装と、固定条件では全Aを固定する実装の定義を確認する。参照固定を外した実験は座標ゲージの影響を見る探索条件に限り、主結果に混ぜない。
- **恒等更新の確認**：Aの学習率を0にした共同学習実装が固定整列条件と数値的に一致することを確認する。
- **介入実装の確認**：空介入・自己交換・変換逆変換のみの対照を実施し、既存の数値許容範囲を維持する。
- **直交性**：全保存stepまたは十分な頻度で \(A^\top A\) の誤差を記録する。制約逸脱・NaN・勾配消失をログに残し、失敗実行を成功扱いにしない。
- **情報漏洩**：未見モデルの介入ラベルをA_test適応以外に使わない。最終testは最終評価まで読み込まない設計にする。

## 8. 実施順序と停止基準

1. 開発seed 5234・4641で、単一fold・単一初期化の固定／共同学習を実装し、直交性と損失勾配を確認する。
2. 適応前、適応例数256・1,024・4,096・10,000のA_test適応を開発データで動作確認する。適応testは開発試行の技術的確認にのみ使用し、本試験評価には使わない。
3. A用学習率、直交パラメータ化、適応更新数・停止規則を開発結果から決め、設定ファイルとコードrevisionを記録する。
4. 設定凍結後、5seedのleave-one-model-outを学習済み群とランダム群で実施する。各foldで両条件を対応実行する。
5. モデル別結果、paired差、適応曲線、全checkpoint・設定を保存し、解釈表に沿って報告する。

直交性を保てない、固定条件を再現できない、または適応ループでtest情報が混入する場合は本試験に進まず、問題と変更履歴を記録する。PoCで転移改善が見えない場合も、本試験を結果に応じて打ち切らず、事前に定めた範囲で完了し、探索的なハイパーパラメータ探索とは分離する。

## 9. 保存物・再現性

各runについて、φ初期seed、φ checkpoint、A_m⁰と学習後A_m、参照モデル、fold、モデル状態、介入・校正データID、適応subset ID、学習・停止ログ、各splitの予測と指標、直交誤差、更新数、実行環境、コードrevision、確定configを保存する。固定条件と共同条件がペアで追跡できるrun IDを付ける。

共有部分の寄与を対照した5fold・2反復の追試結果：[adaptation_controls_results.md](./adaptation_controls_results.md)（学習済み群）と[random_adaptation_controls_results.md](./random_adaptation_controls_results.md)（ランダム群）。どちらもseed 4287を探索fold、残る4foldを確認foldとして分けて報告する。学習元IIAが低いfold・反復も含むため、ランダム群全体の転移失敗と学習失敗を区別しない。選定したfold 1・共同共有init 1の未見適応診断は[random_fold1_adaptation_diagnostic.md](./random_fold1_adaptation_diagnostic.md)を参照。固定共有写像＋整列だけでは10,000更新でも低IIAだった一方、両方更新するとtrainには過適合し、dev/test回復は限定的だった。これは単一ケースの診断であり、表現限界を確定しない。学習済み群でも単一モデル由来写像が有効であるため、群間差を複数モデル共有固有の効果とは解釈しない。
