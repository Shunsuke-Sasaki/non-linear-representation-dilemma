# モデル間共有と未見モデルへの汎化に基づく非線形対応写像の評価

研究計画案｜文書作成日：2026年10月9日｜実験未実施

本書は会話中に検討した第2の研究計画を実施可能な形に整理したものである。第1計画と共通の設定は継承し、それ以外の数値や学習手順は「推奨する初期仕様」として提示する。開発試行後、本試験の前に確定する。2026年10月9日に一次文献を再調査し、第14章「先行研究との関係と新規性」を追加した。文献検索は選択的レビューであり、同一研究の不存在や新規性を保証するものではない。

## 要旨

非線形対応写像のモデル固有の性質への過剰な適合を抑えるため、単純なモデル別整列と、複数モデルで共有する非線形写像を組み合わせる。課題学習済みMLP群とランダムMLP群で、未見モデルへの介入一致率の汎化を比較し、写像の共有が、課題能力を伴わない高一致率の対応を選別する基準となるか検証する。

## 1. 背景と研究目的

表現力の高い写像をモデルごとに最適化すると、課題能力の低いランダムNNにも高IIAが得られるという問題がある［1］。一方、写像を線形に限定すると、実際に存在する非線形な表現を捉え損なう可能性がある。

本研究は非線形性を一律に禁止せず、その表現力を複数モデルで共有させる。モデルごとに許す自由度を単純な整列に制限し、一つの対応が異なるモデルでも利用できるかを追加の評価軸とする。

ここでいうモデル群・モデルアンサンブルは、同じ課題について異なるシード等で得たNN集合である。出力を平均したり多数決したりする予測アンサンブルではない。各モデルを独立した介入対象として評価する。

### 1.1 研究質問

> 制限された個別整列と共有非線形写像による対応は、未見モデルへの汎化を通じて、課題能力を伴う対応と、課題能力を伴わない高IIA対応を区別できるか。

補助的に、共有学習に使うモデル数、整列の自由度、共有写像の容量、モデル間交換の可否との関係を調べる。

### 1.2 仮説と主張の限界

方向仮説は、学習済みモデル群で未見モデルIIAがより高く維持され、個別適合との差が小さいことである。しかし、学習済みモデルが異なる解法を持つ場合や、ランダムモデルにも利用可能な共通構造がある場合には成立しない。

同じアルゴリズムでも座標配置は異なりうる。したがって共有失敗を共通アルゴリズムの不在と同一視しない。共有成功も真の機構やアルゴリズムの一意性を保証しない。本試験は候補アルゴリズムを一つに固定するため、その候補に関する対応の汎化を測る。

## 2. 先行研究と提案の位置づけ

### 2.1 Model Alignment Search（MAS）

GrantのMASは、モデルごとの整列を用いて表現の一部をモデル内・モデル間で交換し、反実仮想的な出力の一致から因果的な互換性を調べる［3］。一般式は複数モデルと可逆な整列関数を許す一方、v7本文§3.3で実験は2モデルと尺度付き直交変換に限定している。一般枠組みと検証済みの実装を区別する。本計画に最も直接的な先行研究である。

本計画は「モデル間の因果的比較」を初めて導入するものではない。相違は、個別整列と共有非線形写像を分離し、非線形対応の過剰な自由度に対する制約として、未見モデルへの転移を評価する目的にある。

### 2.2 Universal Sparse Autoencoders（USAE）

USAEはモデル別encoder・decoderを通じて共通の疎な概念空間を学習し、あるモデルから得たコードで他モデルの活動も再構成する［4］。共有されるのは概念空間であり、全encoderのパラメータが同一という意味ではない。

本計画もモデル固有部分と共有部分を持つが、活動の再構成に加えて高水準変数への介入一致を問題とする。共通概念の抽出と、アルゴリズム上の因果的役割の共通性は区別する。

### 2.3 共有表現の幾何とmodel stitching

Shared Representational Geometryは、モデルごとの直交変換を介して共通表現を捉える考え方を示す［5］。Model stitchingは低容量の変換を介して別モデルの前段・後段を接続し、性能を保てるかを調べる［6］。Git Re-Basinはニューロンの置換対称性を考慮した整列に関係する［7］。

これらから、単なる座標差を許す必要性と、モデル固有の接続写像を強くしすぎない必要性が導かれる。ただし、共有非線形写像もモデル別処理を内包しうるため、共有だけで過剰適合が消えるとは考えない。

### 2.4 新規性の候補

貢献は、制限した整列と共有非線形対応を用い、学習済み／ランダムの比較および未見モデル評価によって、共有制約の識別力と限界を示すことにある。表現の単純な変換による転移や、モデル群の共通特徴抽出にも先行例がある。第14章でそれらとの境界を論じ、同一構成の先行例が存在しないとの断定は避ける。

## 3. 対応写像の定式化

モデルmの対象層の状態をh_m、後段をF_mとする。可逆な個別整列A_mと可逆な共有写像φを用いて、

$$
z_m=\phi(A_mh_m)
$$

とする。高水準変数に対応する座標集合は全モデルで共通に固定する。モデル内の介入は、

$$
\tilde h_m=A_m^{-1}\phi^{-1}\!\left(\operatorname{Swap}(\phi(A_mh_{m,b}),\phi(A_mh_{m,s_L}),\phi(A_mh_{m,s_R}))\right)
$$

で定義し、F_m(tilde h_m)と反実仮想ラベルを比較する。原モデルを再訓練することはしない。

全モデルで一つのφを共有しても、活動分布からモデルを推定し、領域ごとに異なる処理を学ぶ可能性がある。モデルIDを与えないだけでは防げないため、未見モデル評価を中心に置く。

## 4. 課題・NN・共通設定

| 項目 | 初期仕様 |
| --- | --- |
| 課題 | 階層的等値判定。4個の4次元ベクトル、二値出力 |
| 高水準モデル | Both Equality Relations |
| NN | 3隠れ層、各16次元。公式MLP実装に合わせる |
| 対象層 | 第1隠れ層。テンソル位置は第1計画と同一 |
| 介入 | 左・右・両方を約1/3ずつ。左右各8次元 |
| NN群 | 学習済みと、同一初期化を保存したランダム状態 |
| 主たる共有φ | RevNet 10ブロック、内部幅128 |
| ノイズ | 主試験では加えない |

課題はe_L＝1[x_1＝x_2]、e_R＝1[x_3＝x_4]、T＝1[e_L＝e_R]で定義する。等値事例をコピーで生成し、ラベル頻度を確認する。

MLP学習は第1計画に合わせ、訓練1,048,576、開発・テスト各10,000、Adam、学習率0.001、バッチ1,024、最大20 epoch、開発損失で3 epoch改善なしの停止を初期仕様とする。

## 5. 個別整列A_mの設計

### 5.1 主条件：通常活動に基づく置換整列

推奨する最小条件はニューロンの置換行列P_mである。訓練側モデルの一つを参照モデルに選び、同じ通常入力に対する活動を用いて一対一の座標対応を求める。参照モデルの選び方はシード順等で固定し、最も高いIIAを与える参照を選ばない。

校正入力10,000例について、各座標の活動ベクトルを比較する。例えば、標準化活動の二乗誤差を費用として最小費用の一対一割当を求める。無分散座標の扱いと同点処理は決定的に固定する。標準化は割当の推定に使い、実際に適用するA_mは置換だけとする。

置換は厳密に可逆であり、逆変換は転置で実装できる。一方、分散表現の回転や尺度差は吸収できないため、失敗が整列の制約による可能性は残る。

### 5.2 感度分析：直交整列

置換条件が十分な整列を実現しない場合に備え、通常活動のProcrustes整列による直交行列を補助条件として事前に設定できる。中心化の有無と、中心化する場合の平行移動・逆操作まで明記する。結果を見て良い条件だけを主結果へ昇格させない。

直交変換は置換より自由度が大きい。置換と直交で結論が変わる場合は、許容する座標変換への依存として報告する。モデルごとの自由な非線形整列は主計画に含めない。

### 5.3 学習と評価の分離

A_mは通常活動だけから推定し、介入ラベル、IIA、共有φの損失で更新しない。校正入力は写像選択用の開発集合と最終テスト集合から独立にする。未見モデルでも同じ校正手続きを許すため、評価は完全な無適合転移ではなく「介入ラベルを使わない校正付き転移」と表現する。

## 6. 比較条件

| 条件 | 構成 | 役割 |
| --- | --- | --- |
| 個別非線形 | φ_m(P_mh_m) | 各モデルに適合すれば高IIAが得られるかの参照 |
| 共有線形 | R(P_mh_m)、Rは共有直交変換 | 個別整列を揃えた上で非線形部分が必要か確認 |
| 共有非線形 | φ(P_mh_m) | 主提案 |
| 整列のみ | P_mh_m | 固定座標分割だけでの診断用対照 |

整列のみの条件は、通常活動の整列が高水準の左右変数を分離する保証を持たない。この条件の失敗だけで非線形写像の必要性を結論しない。解釈可能な主対照は共有線形条件とする。

個別非線形条件は評価対象モデルの介入訓練データを利用するため、転移条件と同じ情報条件の競争ではない。個別適合可能性の参照であり、厳密な性能上限でもない。

## 7. シード・分割・学習手順

### 7.1 最小のモデル分割案

開発専用モデル群で実装と設定を決め、本試験には別のNN初期化5シードを用意する。5シードのleave-one-model-out評価を行い、各foldで4モデルを共有学習に使い、1モデルを介入評価から除外する。学習前後は同じ初期化で対応づけ、共有写像を2初期化で学習する。

同一foldの学習済み群とランダム群では同じ参照シードを用いるが、整列行列と共有写像は別々に推定する。両状態を一つのφで同時に学習させる設計ではない。

### 7.2 共有写像の目的関数

訓練モデル集合をM_trainとし、モデルごとの反実仮想分類損失を等しく重みづける。

$$
\mathcal L(\phi)=\frac1{|M_{train}|}\sum_{m\in M_{train}}\mathbb E_i\left[\operatorname{CE}(\operatorname{logits}_m(\tilde h_{m,i}),y_{cf,i})\right].
$$

モデルを均等にサンプルし、共通の介入IDを利用する。全NNとA_mを凍結し、φだけを更新する。主評価用のモデルから勾配や開発IIAを取得しない。

写像学習の初期仕様は、介入訓練1,280,000件、開発10,000件、Adam、学習率0.001、合計バッチ6,400、最大50 epochとする。4モデルでは一更新内の例数を均等に割り当てる。epochを全介入IDの一巡と定義するか、固定更新数と定義するかを開発段階で確定し、個別条件との計算量差を報告する。

停止は訓練側4モデルの開発損失平均を用い、改善閾値0.001、5 epoch改善なしを初期案とする。監視する損失の尺度や集約方法は実行前に固定する。平均に加えモデルごとの開発IIAも保存するが、事後的な選択には使わない。

### 7.3 学習回数の目安

共有非線形・共有線形それぞれは、5 fold×2モデル状態×2写像初期化＝20回である。個別非線形は5モデル×2状態×2初期化＝20回で、fold間で再利用できる。主比較の写像学習は合計60回を目安とする。整列のみは写像学習を必要としない。直交整列などの追加条件は別予算とする。

この回数は本書の初期案であり、従来のノイズ計画の40回とは異なる。既存checkpointを再利用する場合、データ分割と評価モデル非参照の条件を満たすか確認する。

## 8. 評価と統計単位

### 8.1 主評価：未見モデルのモデル内介入

未見モデルについてA_newのみ校正し、φを固定して共通のテスト介入10,000例を評価する。IIAをモデル別・介入種類別に報告し、共有学習モデルでのIIAも併記する。

主要な状態間比較は、各シードで共有非線形の未見IIAを写像初期化2回で平均し、学習済み−ランダムの対応差を求めることとする。補助量として、同一モデルの個別IIA−転移IIAを「個別適合との差」として報告する。この差は負にもなりうる。

個別ランダム条件に高IIAがない場合、共有制約による選別の証拠は得られない。高IIAが得られたシードのみを本結果にせず、全試行を提示する。通常課題精度も必ず併記する。

### 8.2 集計上の注意

5foldは訓練モデルを共有するため独立ではない。全モデルの点、平均、範囲を中心に報告し、単純な独立5標本の検定や通常のbootstrapを主要な確証としない。介入10,000例をモデル数の代わりに数えない。

確証的な次段階では、互いに独立したモデル群を複数作るか、共有写像の訓練群を固定して多数の独立テストモデルを追加する。必要数は予備実験の分散と計算量から設計する。

### 8.3 補助的な分解

- 左のみ、右のみ、両方。
- 高水準介入で出力が変わる例と変わらない例。
- 個別・共有の両方がノイズゼロで成功する共通部分の規模。
- 整列誤差、活動ノルム、出力マージンと転移IIAの関係。
- 参照モデルの選択への感度。ただし参照選択でテスト成績を最適化しない。

## 9. 追加実験：モデル間交換

対象モデルmのbaseと別モデルnのsourceを使い、共通空間の同じ部分を交換する。

$$
\tilde h_{m\leftarrow n}=A_m^{-1}\phi^{-1}\!\left(\operatorname{Swap}(\phi(A_mh_{m,b}),\phi(A_nh_{n,s}))\right).
$$

目標ラベルは対象baseの高水準状態とsource入力の交換変数から決める。両変数交換時のsourceモデルの選び方は事前固定する。

モデル内介入の成功が、モデル間で同じ値を交換できることまで意味するかを検証する。最初はモデル内介入だけでφを学習し、モデル間交換は評価専用とする。モデル間交換も学習する拡張はMASにより近い別条件として分ける。

モデル内では成功しモデル間で失敗する場合、共通空間にモデル固有の符号化が残る可能性がある。ただし交換に伴う分布の違いでも失敗しうるため、モデル別分岐を証明したとは解釈しない。

## 10. 正負の対照と数値検証

| 対照 | 目的 |
| --- | --- |
| 同一モデルのニューロン置換コピー | 同じ機構なのに座標差だけで失敗しないか確認 |
| 元の置換を既知として戻すoracle整列 | 写像評価と整列推定の失敗を分離 |
| 通常活動から推定した整列 | 実際の整列手続きが既知の座標差を回復できるか確認 |
| ランダムモデルの個別高IIA | 選別対象が実際に構成できているか確認 |
| 空介入・自己交換・変換逆変換のみ | 恒等操作と数値精度を確認 |

置換コピーは課題機構の忠実性を証明する正の対照ではなく、座標変換への整合性の対照である。真の説明を残す能力を測るには、既知の中間計算を埋め込んだ別の正の対照が必要である。

## 11. 交絡と結果の解釈

| 観察 | 許される解釈 |
| --- | --- |
| 学習済み群だけ未見IIAが高い | 課題学習に伴う共通性を追加基準が捉えた予備的証拠 |
| 両群とも未見IIAが高い | 共有・転移だけでは課題能力を伴わない高IIAを排除しない |
| 学習対象では高IIA、未見では低IIA | モデル集合への適合、校正の失敗、表現差などが残る |
| 置換では失敗、直交では成功 | 許容する座標変換への依存がある |
| 両群とも共有失敗、個別では成功 | 共通性不足、整列不足、容量・最適化の問題を区別する必要 |
| モデル内成功、モデル間交換失敗 | 同じパラメータの利用だけでは値の互換性まで確立しない |

容量の大きいφは暗黙にモデルを識別できる。また整列と共有写像を同時にIIAで更新すると役割分担が曖昧になるため、主設計では整列を先に固定する。モデルごとの尺度差を残す置換整列には限界があるが、補正を増やすほど個別自由度も増える。このトレードオフを結果とともに報告する。

複数の候補アルゴリズムが同じ介入結果を予測する可能性も残る。アルゴリズムの特定を目指す次段階では、競合候補が異なる予測を出す介入を設計する。

## 12. 実施計画と保存物

1. 公式課題と個別非線形高IIAを開発モデルで再現する。
2. 置換コピーを使い、整列・逆操作・交換を検証する。
3. 整列の費用、参照規則、校正データ、更新予算、停止規則を固定する。
4. 5シードの本試験とleave-one-model-out評価を実施する。
5. 全条件のモデル別IIAと個別適合との差を報告する。
6. モデル間交換と整列自由度の分析を追加実験として実施する。

保存物はNN・写像checkpoint、A_m、参照モデルID、モデル分割、校正入力ID、介入データ・乱数シード、学習ログ、モデル別予測、通常精度、整列費用、設定とコード差分である。未見モデルの情報を何に利用したかを監査できる形にする。

計算時間は開発用の1foldから見積もる。モデル数を増やす実験では、総更新数固定とモデルごとの更新数固定を区別し、データ量・計算量の増加を共有の効果と混同しない。

| 主指標 | Q、IIA、B | 未見モデルIIA、個別適合との差 |
| 主な交絡 | NN後段の感度・マージン | 整列の不足・解法差・暗黙のモデル識別 |

両計画は独立に評価できる。初期段階でノイズと転移を同時に主条件へ入れると失敗原因が増えるため、まず別々に実施する。統合段階では、未見モデルに転移した対応の介入後ノイズ頑健性を測り、二つの基準が同じ対応を選ぶかを調べる。

### 14.1 調査の範囲と判定の基準

検索は、DAS・MAS・非線形表現ジレンマを起点に、共有概念空間、model stitching、表現空間の変換、crosscoder、回路のモデル間転移へ広げた。主な検索語は `Model Alignment Search shared nonlinear multiple models`、`shared nonlinear causal abstraction`、`Relative Representations Enable Zero-Shot Latent Space Communication`、`Latent Space Translation via Semantic Alignment`、`crosscoders model diffing` である。2026年の関連プレプリントも対象にした。

一次資料の方法と実験条件を確認し、「複数モデルを一つの空間で扱う」「同じパラメータを共有する」「同じ因果変数を交換する」「未見モデルで成立する」の四点を別々に比較する。これらは互いに同値ではない。以下の相違点・推奨対照は、本計画側の分析として記す。

### 14.3 MASに対して何を追加するのか

MASの一般式は各モデルに可逆な整列関数を置く［3、§3.3］。したがって、A_mとφが可逆なら、合成φ∘A_mはその一般的な写像クラスに含まれる。この包含関係は本計画の数式からの帰結であり、「MASにない可逆非線形写像を初めて理論上許す」とは主張できない。

本計画で追加するのは、合成写像の**因数分解と学習時の制約**である。

1. モデル固有部分A_mは、通常活動で推定した置換等に限定し、先に固定する。
2. 介入整合性で学習する高容量部分φのパラメータをモデル間で共有する。
3. 評価モデルの介入ラベルを使わず、φを凍結したまま評価する。
4. 学習済み群とランダム群を比較し、共有制約に選別能力があるかを問う。

また、現在の主試験はモデル内交換のみで共有φを学習する。これはMASのモデル間交換を含む学習と同じではない。第9章のモデル間交換を導入した際も、それを評価専用にした条件と、学習目的に加えた条件は分離する必要がある。一般枠組みが多モデルを扱うことと、未見モデル転移が実証されたことを取り違えない。

### 14.4 「簡単な整列＋複雑な共有処理」はどこまで既存か

**表現の転移。** Relative representationsはアンカーとの類似度を用い、Latent Space Translationは単純な代数的変換を介してencoder・decoderを再利用する［10,11］。このため、座標差を補正して既存の複雑な処理を再利用する設計一般は新規ではない。本計画の追加点は、その処理を候補アルゴリズムの介入変数へ対応づけるφとして学習し、課題能力を伴わない高IIAを対照にする目的にある。

**共有概念空間。** USAEでは各モデルが独自のencoder・decoderを持つ［4、方法§3.1～3.2］。共通コードと、同一パラメータの可逆φは同じ条件ではない。共有φは通常の活動再構成を直接目的としないため、本計画がUSAEより忠実であるとも、共有空間がより普遍的であるとも、比較実験なしには言えない。

**Crosscodersからの注意。** Minderらは、共有特徴の学習目的に由来するアーティファクトが、概念をモデル固有と誤認させうることを示す［13、要旨］。Jiralerspong・Brickenは異なるアーキテクチャ間のcrosscoderを扱い、単純な表現翻訳を介したsteeringの転移も評価する［14、§3.2.2・付録B.5］。したがって「特徴をモデル間で移して効果を比べる」という実験自体も既存である。

この系統から本計画への含意として、共有構造を学習するよう設計したことと、元のNNに共有機構が存在する証拠を得たことを区別する。未知モデル・既知機構の対照・一部のモデルだけ異なる機構を持つ条件が、共有を強制したことによる見かけの成功を点検する手段になる。ただし、crosscoderの特定の失敗機構がRevNetにも生じると断定するものではない。

### 14.5 「未見」の種類を分ける

| 汎化軸 | 具体例 | 本計画との関係 |
| --- | --- | --- |
| 未見入力 | 同じNNで新しいbase・sourceを使う | 通常のテスト分割。必須だがモデル転移ではない |
| 未見の語彙・実体 | 原論文のIOIにおける未見の名前［1］ | 原論文がすでに持つ追加評価 |
| 未見課題 | DFAのleave-one-task-out［15、§4.1］ | 対応行列の学習対象の課題を変える。未見モデルとは別 |
| 未見モデル | φ学習に含めなかった初期化シードのNN | 本計画の主評価 |
| 未見の介入形式 | 学習時にない変数組合せ等 | 本試験の成功条件には含めない |

DFAのzero-shotは、本文で訓練課題を除外する設定として定義されている［15］。本計画はモデル単位で除外するが、通常活動によるA_newの校正は許すため、「何の適合もないzero-shot」とは表現しない。source・targetの通常活動が校正に必要であることも情報条件として記録する。

### 14.6 新規性の主張と、その強さ

| 主張候補 | 判断 |
| --- | --- |
| 複数モデルの共通表現を初めて抽出する | 主張しない。共有表現・USAE・Crosscoders等がある |
| モデル間で因果変数を交換する最初の方法 | 主張しない。MASが直接の先行研究 |
| 単純な整列後に複雑な処理を再利用する構成が新しい | 構成一般については主張しない。stitching・表現翻訳に先行例 |
| 非線形共有φが必ず恣意的対応を排除する | 主張できない。暗黙のモデル識別や共通の抜け道が残る |
| 制限した校正と共有非線形φを、未見モデル・学習済み／ランダムで評価 | 具体的な貢献候補。共有の効力を診断する実験に独自性を置く |
| 成功によって共通アルゴリズムを一意に特定した | 主張できない。候補間の識別と中間計算の検証が別途必要 |

確認した一次資料の範囲では、本書の「通常活動のみの制限されたA_m」「共通の可逆非線形φ」「未見シードへのφ固定転移」「個別では高IIAとなるランダム条件との比較」を一体として評価する同一実験は見つからなかった。この限定付きの検索結果を、手法の独創性や採録可能性の保証には用いない。

貢献の記述案は、「本研究は、非線形対応をモデル間で共有し、モデル固有の適合を制限した校正に限定することで、未見モデルへの介入汎化が高IIAの解釈に与える追加制約を評価する」である。

### 14.7 調査から必要になる追加の比較・証拠

以下は新規性の解釈を強めるための追加提案である。現在の主試験60回にはまだ含めず、採用する場合は本試験前に予算と解析を更新する。

**優先度1：一つのモデルで学習したφの転移。** 参照モデルだけでφを学習し、同じ整列手続きで未見モデルへ適用する条件を置く。これにより、「単純な表現翻訳で既存写像を再利用できた」効果と、「複数モデルで共有学習する必要があった」効果を分ける。個別φ_mを評価モデル自身で学習する既存対照だけでは、この違いを測れない。

**優先度2：共有の有無だけを変える比較。** 同じA_m・各φの構成・入力IDを用い、φ共有とφ_m独立を比較する。独立条件の総パラメータ数は大きいため、総容量を完全に統制した因果効果とは表現しない。更新数、モデルあたりの訓練例数、最適化失敗率を記録する。

**優先度3：既知の同一機構と異機構。** ニューロン置換コピーは座標対称性の対照である。これに加え、同じ入出力を持つが異なる中間計算を行う既知モデルを用意すれば、共有基準が何を区別しているかを直接点検できる。CAEの既知対照による指標検証［16］が設計上の参考になるが、その結果が転移IIAの妥当性を保証するわけではない。

**優先度4：整列誤差と意味的対応の分離。** 低い活動整列誤差は、同じ高水準変数を表している証拠として十分ではない。oracle整列と推定整列、介入種類別の転移を併記し、失敗を共通アルゴリズムの不在と即断しない。

上記を実施しなくても最小予備実験は成立するが、その場合の主張は「共有写像の転移挙動を記述した」にとどめる。共有制約によって説明の妥当性が改善したという強い主張には、個別高IIAだけでなく、追加の対照が必要である。
