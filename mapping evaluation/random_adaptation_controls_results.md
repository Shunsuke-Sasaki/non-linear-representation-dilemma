## 実験仕様と検証

学習済み群と同じ手順を、random状態の5-fold、4条件、2最適化反復、適応例数0・256・1,024・4,096・10,000に適用した。全200測定が完了した。fold 0（未見seed 4287）は探索用、fold 1–4（3837、9097、2635、5137）は確認用として区別する。

- 比較条件は共有なし（恒等写像）、単一モデル由来、通常活動整列を固定した従来共有、直交整列と共同学習した共有。
- 未見モデルでは写像φを固定し、初期通常活動整列から直交整列A_testだけを更新した。Adam lr 0.001、最大2,000更新、batch size 256とし、adapt-devを200更新ごとにcheckpoint選択に用いた。
- 適応train/devは別々のseedで作成し、最終IIAは未使用testで測定した。adapt-train IDとtest IDは、学習済み群の実験と全て一致することを確認した。
- 10個のfold×反復測定で、条件・適応例数の重複はなかった。直交誤差は適応後で最大 \(9.54\times10^{-7}\)、共同学習で保存した訓練側整列でも最大 \(7.75\times10^{-7}\)。
- 共同写像checkpointは10/10。fold 0・反復0はseedと学習手順が一致する既存PoC checkpointを再利用し、残り9個を本実験で学習した。
- 反復0/1は対応する写像初期化と適応最適化seedを変えた反復であり、独立モデル群ではない。foldも同じ5モデルのleave-one-out分割なので、以下は記述統計として扱う。

実行ログ上の所要時間は約46分。保存された共同写像学習時間の合計は約69分で、再利用したPoC学習時間を含む。環境上のログ計時方法が異なるため、壁時計時間とcheckpoint内の学習時間合計は一致しない。

## 全5-foldの絶対IIA

各セルは10個のfold×反復測定の平均。括弧内はその10測定の最小–最大で、信頼区間ではない。

| 適応例 | 共有なし | 単一モデル由来 | 従来共有 | 共同学習共有 |
| ---: | ---: | ---: | ---: | ---: |
| 0 | 0.4998 [0.4992–0.5008] | 0.5015 [0.4971–0.5095] | 0.4998 [0.4972–0.5018] | 0.5002 [0.4960–0.5044] |
| 256 | 0.4998 [0.4992–0.5008] | 0.5013 [0.4970–0.5085] | 0.4999 [0.4868–0.5062] | 0.5001 [0.4955–0.5044] |
| 1,024 | 0.4998 [0.4992–0.5008] | 0.4981 [0.4895–0.5109] | 0.5001 [0.4926–0.5062] | 0.4988 [0.4876–0.5098] |
| 4,096 | 0.4998 [0.4992–0.5008] | 0.4983 [0.4902–0.5038] | 0.5020 [0.4937–0.5082] | 0.5005 [0.4924–0.5128] |
| 10,000 | 0.4998 [0.4992–0.5008] | 0.5012 [0.4934–0.5090] | 0.5022 [0.4828–0.5285] | 0.4999 [0.4921–0.5047] |

IIAは全条件・全適応例数でほぼ0.5のままであり、適応曲線に実質的な回復は見られない。適応例を増やしても共有なし条件は0.4998で変化せず、共有条件も全体平均で0.498–0.502の範囲にとどまった。

## 共有によるpaired差

同じfold・最適化反復のIIA差を平均した。10個のfold×反復ペアのうち正差となった数も併記する。

| 適応例 | 単一モデル − 共有なし | 従来共有 − 共有なし | 共同共有 − 共有なし |
| ---: | ---: | ---: | ---: |
| 0 | +0.0017 (3/10) | −0.0001 (2/10) | +0.0003 (3/10) |
| 256 | +0.0015 (4/10) | +0.0001 (5/10) | +0.0003 (4/10) |
| 1,024 | −0.0017 (4/10) | +0.0003 (4/10) | −0.0011 (3/10) |
| 4,096 | −0.0016 (4/10) | +0.0021 (5/10) | +0.0006 (4/10) |
| 10,000 | +0.0014 (6/10) | +0.0024 (6/10) | +0.0001 (7/10) |

最大の平均差もIIAで0.0024（0.24ポイント）で、正差が全ペアに一貫している条件はない。共有写像が未見randomモデルの適応を助ける証拠とは解釈できない。小さな差はテスト標本・最適化反復の揺らぎと区別できず、独立したモデル群に対する統計的検定でもない。

## 個別写像のIIAと解釈上の制約

既存の個別写像IIA（seedごとに2初期化）は次の通り。各foldの適応結果と併せて、ランダム群の異質性を判断する。

| 未見seed | 個別写像IIA（init 0 / init 1） | 平均 |
| ---: | ---: | ---: |
| 4287 | 0.4970 / 0.4991 | 0.4980 |
| 3837 | 0.7417 / 0.7224 | 0.7321 |
| 9097 | 0.4972 / 0.4998 | 0.4985 |
| 2635 | 0.8041 / 0.4972 | 0.6506 |
| 5137 | 0.4955 / 0.4980 | 0.4967 |

多くのrandomモデルでは個別写像自体がchance付近である。一方、seed 3837では個別写像が0.72–0.74、seed 2635では一方の初期化が0.80だった。それでも、これらの未見foldで共有写像を固定しA_testだけ適応したIIAはほぼ0.5だった。したがって、ランダム群全体の低IIAを共有方式だけの失敗とは結論できないが、個別写像で高IIAが得られるモデルについても、この適応手続きで共有写像の利益は再現されなかった。

## 共有写像の学習元モデル上でのIIA

転移以前に共有写像が学習対象で対応を得ていたか確認するため、各foldの訓練側4モデルで写像を評価した。IIAは共有写像の学習に使っていないtest介入10,000例で測定し、共同学習条件ではcheckpointに保存された学習後整列 \(A_m\) を使用した。各セルはそのfold・初期化の訓練側4モデルの平均IIAと、モデル間の最小–最大である。init 0/1は別々の最適化反復であり、平均化していない。

| fold（heldout seed） | 従来共有 init 0 | 従来共有 init 1 | 共同共有 init 0 | 共同共有 init 1 |
| --- | ---: | ---: | ---: | ---: |
| 0 (4287) | 0.5037 [0.4969–0.5092] | 0.7320 [0.6593–0.7633] | 0.7720 [0.7145–0.8042] | 0.7719 [0.7143–0.7990] |
| 1 (3837) | 0.5015 [0.4971–0.5084] | 0.7415 [0.6847–0.7786] | 0.5020 [0.4961–0.5101] | 0.7441 [0.6863–0.7685] |
| 2 (9097) | 0.4978 [0.4858–0.5036] | 0.4997 [0.4934–0.5058] | 0.5046 [0.4956–0.5105] | 0.5037 [0.4946–0.5122] |
| 3 (2635) | 0.4993 [0.4867–0.5099] | 0.4985 [0.4949–0.5027] | 0.4984 [0.4931–0.5062] | 0.4999 [0.4934–0.5049] |
| 4 (5137) | 0.5019 [0.4980–0.5048] | 0.4938 [0.4907–0.4975] | 0.4985 [0.4942–0.5053] | 0.4971 [0.4899–0.5001] |

**この診断では、学習元での適合が全fold・反復に成立していたわけではない。** 共同共有は10反復中3反復（fold 0の両反復、fold 1のinit 1）で訓練側平均IIAが約0.74–0.77になったが、残る7反復は約0.50だった。従来共有も10反復中2反復（fold 0/1のinit 1）だけが高く、残りはchance付近である。したがって低IIAの反復では、未見への転移を論じる前に、共有写像の学習自体が成功していない。

一方、source-side IIAが高い共同共有のfold 0両反復でも、対応するheldout IIAは適応10,000例後にそれぞれ0.4998、0.4997だった。従来共有でもfold 0/1のinit 1は訓練側で高IIAだったが、heldout適応後はそれぞれ0.5150、0.5023にとどまる。よって、学習対象で高IIAを得ても、今回の未見側適応で回復するとは限らない。

### 最適化失敗と表現限界の区別

直交誤差が小さいことは制約の維持を示すだけで、最適化の十分性を示さない。この懸念は実測値にも表れており、学習対象のIIAがchance付近の7/10共同反復では、保存された学習履歴のbest dev lossもおおむね0.693付近で、dev IIAは各モデル約0.49–0.52だった。これは学習中に有効な対応を得られなかったことを示すが、写像の表現能力が不足していたのか、最適化・初期化・学習予算に問題があったのかは判別できない。

対照実験本体では未見適応中のtrain曲線は保存していなかったため、fold 1・共同共有init 1を対象に個別診断を追加した。その結果、固定写像＋直交整列だけでは10,000例・10,000更新でもtrain/dev/testはchance近辺だった。初期化を3つのランダム直交行列に変えても結果はほぼ同じだった。さらに診断として写像と整列を両方更新するとtrain IIAは0.966まで上がったが、dev lossが悪化し、dev選択test IIAは0.564にとどまった。曲線・勾配・行列更新および過適合の詳細は[random_fold1_adaptation_diagnostic.md](./random_fold1_adaptation_diagnostic.md)を参照。

## 判断

今回のランダム群では、共有なし・単一モデル由来・従来共有・共同学習共有のいずれも適応後にchanceを超える回復を示さず、共有写像の有無や学習元による実質的な差も見られなかった。限定診断では、選定したfold 1で整列だけを更新する適応の失敗がtrain/dev/testにわたり確認され、写像と整列を同時に更新するとtrainに過適合する傾向が見られた。この一例は失敗箇所を絞るが、他foldへの一般化や表現能力の限界を確定しない。randomモデルの多くは個別写像でも課題能力を示さないため、「課題能力を伴う対応なら共有が役立ち、そうでなければ役立たない」という因果的な結論には、個別IIAが高いrandomモデルを事前に特定した独立検証が必要である。

この結果は「複数モデル共有だけが選別を可能にした」ことも示さない。学習済み群では単一モデル由来写像も共有なしを上回っており、従来共有・共同共有の単一モデル由来条件に対する上積みは相対的に小さい。現時点で妥当な結論は、**非線形写像の再利用可能性に学習済み群とランダム群で差が観測された**という範囲にとどめ、複数モデル共有に固有の選別効果とは区別することである。
